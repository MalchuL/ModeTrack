# Productivity App: How to Use

> The app is single-user only.

## Tasks

- Open the **Tasks** tab to search existing items by name or tags.
- Sorting is fixed: overdue items first (highlighted red), with **In Progress** shown before **TODO**. Next come non-overdue **In Progress**, then **TODO**. Priority does not affect sorting.
- Within each status group you can drag and drop to reorder tasks.
- You can also drag tasks between status groups.

### Create tasks

- Click the **+ New Task** button.
- Or type a task name in the search bar and press Enter. Add tags inline with `#tag` or `№tag` (for Cyrillic keyboards). Set priority inline with `!1` (low) through `!4` (urgent).

### Edit tasks

- Click a task card (or the pencil icon) to open the editor.
- Click the status badge to switch between **TODO** and **In Progress**.
- Click the priority badge to set the priority. Priority is for display only and ignored in sorting.
- Tags must be comma separated in the editor.

## 12 Week Year

- Create cycles to track goals over 12 weeks (or a custom length).
- Each goal has its own calendar. Click a day to mark it green when you did work; missed days turn red automatically.
- Overlapping cycles are allowed but discouraged; you will see a warning if dates overlap.

## Focus Times

- Pomodoro-style focus timer. Core flow works, but the feature is still in development.
